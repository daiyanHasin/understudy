01 — RECORD

Record on a virtual device. Or on the phone in your hand.

Plug in a phone, connect it over Wi-Fi by QR code or 6-digit code, or start a light Android emulator. Click an element inside Understudy and choose what to do with it, or switch to From phone and just use the app.

Every action becomes a step

Taps, long presses, swipes, typing and checks turn into readable Maestro steps with the best target already picked.

  • Targets by ID, text, label and placeholders like “Enter email”, plus ID + text and index for lists
  • Hover inspector shows every element's selectors, counted the way Maestro counts them
  • From device keeps only touches in your app
  • Pick any installed app, or add and install an APK
  • Clean-state snapshots for repeatable runs
02 — DATA-DRIVEN

Hard-coded or test data? Decide as you type.

No more copying values into ${output.Email} by hand. Pick the Excel file, sheet and column, and Understudy writes both the flow and the spreadsheet.

One flow, every row

The value you typed becomes row 1. Add more rows and run the same flow for each of them, each with its own report.

  • Existing file and sheet, new sheet, or new file
  • Existing columns suggested; values never overwritten
  • Leading zeros kept, passwords masked
  • Run rows 1, all, 2-5 or 1,4-6,10
03 — EDIT

Steps you can shape. YAML you can own.

Change a tap into a check, pick a better target, move steps, wrap them in loops and conditions — or edit the YAML and watch the steps follow.

Conditions and loops, built in

Repeat N times, repeat while something is visible, run only if a popup appears, retry flaky steps. They're Maestro's own commands, so your flows stay portable.

  • Two-way flow editor with any Maestro command
  • Tick steps and wrap them in a block
  • Variables, copy text into a variable, if / else on any condition
  • Non-unique targets flagged before they bite
  Flows/Login/login_valid.yaml
appId: com.shopeasy.app
---
- runScript: "../../Scripts/ShopData/Login.js"
- launchApp:
    clearState: true
- runFlow:                       # If visible
    when:
      visible: "Allow notifications?"
    commands:
      - tapOn: "Allow"
- tapOn:
    text: "Enter your email"
- inputText: "${output.Email}"
- retry:                         # Retry
    maxRetries: 3
    commands:
      - tapOn: "Sign in"
      - assertVisible: "${output.Expected}"

HOW IT WORKS

Three steps from APK to a passing suite.

Set up once

Install Node.js, Java and the Maestro CLI. Double-click Understudy.vbs (works behind company HTTPS inspection too); Setup tells you what's missing.

Record

Connect a phone, pick the app, and click through the flow. Choose fixed text or test data for every value you type.

Run and repeat

Pick flows and rows, run, and read the live steps, reports and dashboard. Add rows to Excel to test more cases.

PRIVACY & SECURITY

Your app stays yours.

Understudy is a local app. There is no server to send your APK to, and nothing to sign in to.

Local only

The server listens on 127.0.0.1. APKs are copied into a folder on your PC and installed with adb. No telemetry.

Locked to its own window

A fresh session token every start, plus Host and Origin checks, so other websites can't control it.

No shell tricks

adb and the emulator run without a shell, and every argument sent to the device is quoted.

Reports in a sandbox

Maestro's HTML reports are shown sandboxed and can't reach the app.

FAQ

Questions, answered.

Do I still need Maestro Studio or Android Studio?

No. Understudy records flows itself, and Setup can install the Android tools (adb, the emulator and a light virtual device) without Android Studio. You need the free Maestro CLI, which runs the tests.

Is it free?

Yes, free to download and use for personal and internal testing. It's proprietary software: redistribution or reselling needs permission.

Does my APK get uploaded anywhere?

No. "Add APK" copies the file into the Apps/ folder on your PC, and it's installed on the device with adb.

Can I use my existing Maestro flows?

Yes. Put them in Flows/ to run them. Paste one into the recorder's Flow panel to edit it with the step list — commands Understudy doesn't know are kept as custom steps.

Does it support iOS, macOS or Linux?

Not yet. Understudy 1.x targets Android on Windows. macOS and Linux are on the roadmap.

Is it affiliated with Maestro?

No. Understudy is an independent project that runs the Maestro CLI installed on your machine. "Maestro" is used only to describe compatibility.
