Connect a device

A phone by USB or Wi-Fi is the fastest option. No Android Studio needed.

Install phone tools first

Understudy talks to phones through Google's official platform-tools (adb). One download, about 8 MB, kept inside Understudy's folder.

  1. Turn on developer options. Settings › About phone › tap Build number seven times. On Xiaomi it is MIUI version, on Samsung it is under Software information.
  2. Turn on USB debugging. Settings › System › Developer options › USB debugging. On Xiaomi also turn on USB debugging (Security settings).
  3. Plug the phone in and tap Allow. Unlock it and accept “Allow USB debugging?”. Tick Always allow from this computer.
Watching for a phone…
The phone is plugged in but nothing shows up
  • Use a data cable. Many charging cables have no data wires.
  • Pull down the notification shade, tap the USB notification and choose File transfer.
  • Windows: Samsung, Xiaomi and some others need the maker's USB driver (search “<brand> USB driver”). Pixel phones use the Google USB driver.
  • Still stuck: in Developer options choose Revoke USB debugging authorizations, unplug, plug in again and tap Allow.
Pair with a QR code
  1. Phone and this PC on the same Wi-Fi network.
  2. Phone: Developer options › Wireless debugging › turn on.
  3. Tap Pair device with QR code and scan this code.

Android 11 or newer. Paired phones reconnect from the same screen later without a code.

Pair with a 6-digit code, or connect by address
  1. First time on this PC: on the phone tap Wireless debugging › Pair device with pairing code and keep that window open.
  2. Enter the IP address & port and the code shown in that window. Understudy pairs, then finds the connection address by itself.
  3. Paired before? Leave the code empty and enter only the IP address & Port from the top of the Wireless debugging screen.
Phone already connected by USB? Move it to Wi-Fi

Works on every Android version, also where the QR code and pairing code don't. Keep the cable in until it says connected. The Wi-Fi connection lasts until the phone restarts.

Wi-Fi doesn't work at the office?
  • Same network. The phone and this PC must be on the same Wi-Fi. A PC on a network cable is often on a different office network.
  • Office and guest Wi-Fi often keep devices apart (“client isolation”) and block how phones announce themselves. Check connection tells you when that is the case. Then connect the phone to this PC's Mobile hotspot (Windows Settings › Network › Mobile hotspot), or record over USB.
  • Firewall. If Windows asked whether adb.exe may use the network, it must be allowed on private networks. On a managed PC, IT may have to allow it.
  • VPN or security client on this PC can block local traffic. Ask IT to allow the local network, or use USB.
  • Phone asleep. Keep it unlocked, or turn on Developer options › Stay awake while charging. Wireless debugging turns off when the phone changes Wi-Fi.

What Understudy needs

Free, and everything stays on this PC

Phones

No Android Studio needed

A USB or Wi-Fi phone only needs Google's platform-tools (adb). Understudy downloads it into its own folder when you press Install phone tools (about 8 MB, no admin rights, nothing else changed). Wi-Fi phones pair by scanning a QR code.

Virtual devices

Optional

Only if you want to test without a phone. Installs the emulator and one light system image from Google's official server, then creates Understudy_Pixel (2 GB RAM). About 1.5 GB to download. A window shows the progress.

Free memory

After you close a virtual device, the emulator, adb and Android Studio can keep gigabytes of memory. Understudy ends the emulator itself when you press Stop; use this to end everything Android-related at once.

Typing non-English text

With the live screen, Bengali and any other script is typed through the device clipboard, nothing to install. Without it, install the free, open-source ADB Keyboard app on the device once (add its APK on the Record tab and press Install).
